# Contributing

Thank you for helping improve this project.

## Good first contributions

- Add accurately sourced topic tags
- Improve explanations
- Add practice questions
- Fix accessibility issues
- Improve documentation
- Add tests or validation scripts

## Pull request process

1. Fork the repository.
2. Create a focused branch.
3. Make a small, clearly described change.
4. Verify that the site still works.
5. Open a pull request explaining what changed and why.

## Content standards

- Prefer primary or authoritative sources.
- Do not copy copyrighted coaching material.
- Do not upload paid study material.
- Cite sources for factual additions.
- Keep educational claims transparent and verifiable.
