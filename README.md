# UPSC CSE Study Toolkit

An open-source, lightweight study toolkit for UPSC Civil Services Examination preparation.

## What this project provides

- Topic-wise UPSC syllabus structure
- PYQ tagging and analysis-ready data format
- Mains answer-writing framework
- Revision tracking
- Prelims practice question format
- Contribution guidelines for students, teachers, and developers

> This project is an independent educational resource and is not affiliated with UPSC.

## Quick start

No build tools are required.

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Explore the syllabus, answer framework, and sample question bank.
